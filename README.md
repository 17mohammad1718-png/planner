# Planner — اپ مدیریت ایده، پروژه، عادت و کار روزانه

> تقویم کامل شمسی + میلادی | ایده‌ها | پروژه‌ها | عادت‌های روزانه | کارهای روزانه

این ریپو برای ساخت اپ اندرویدی **Planner** هست. پلن کامل در [`PLAN.md`](./PLAN.md) قرار دارد.

## هدف
یه اپ اندرویدی که بتونی:
- 💡 ایده‌هات رو ثبت و پیگیری کنی
- 📁 پروژه‌هات رو مدیریت کنی
- 🔁 عادت‌های روزانه رو تیک بزنی و استریک بسازی
- ✅ کارهای روزانه رو ثبت کنی
- 📅 همه‌ش رو روی یه تقویم کامل شمسی/میلادی ببینی

## تکنولوژی پیشنهادی
`Expo + React Native + TypeScript + expo-sqlite + jalaali-js`

## شروع سریع (بعد از اسکافولد)
```bash
npm install
npx expo start
# برای بیلد APK:
eas build -p android --profile preview
```

پلن رو ببین: [PLAN.md](./PLAN.md)
