# Planner — اپ مدیریت ایده، پروژه، عادت و کار روزانه

> تقویم کامل شمسی + میلادی | ایده‌ها | پروژه‌ها | عادت‌های روزانه | کارهای روزانه

اپ اندرویدی **Planner** — تمام جزئیات در پلن: [`PLAN.md`](./PLAN.md)

**وضعیت: ✅ فاز ۰، ۱ و ۲ (غیر از بیلد EAS) پیاده‌سازی شده**

## امکانات

- 💡 **ایده‌ها** — ثبت با توضیح، تگ و وضعیت (خام / در بررسی / شروع شده / آرشیو)
- 📁 **پروژه‌ها** — ددلاین، تسک‌های زیرمجموعه، نوار پیشرفت خودکار و وضعیت
- 🔁 **عادت‌ها** — تیک روزانه، استریک (روزهای متوالی)، آیکون و رنگ، نمایش ۷ روز اخیر
- ✅ **کارهای روزانه** — تاریخ (با انتخابگر شمسی)، ساعت، اولویت، تکرار (روزانه/هفتگی)، فیلترهای امروز/دیر شده/انجام شده
- 📅 **تقویم** — ماه‌نمای شمسی/میلادی (با سوییچ)، نقطه‌گذاری روزها (کاری/عادت/ددلاین)، کلیک روی روز = لیست کامل آیتم‌های آن روز
- 🏠 **خانه** — داشبورد: پیشرفت کارهای امروز، تقویم ماه جاری، عادت‌ها، ددلاین‌های نزدیک، ایده‌های اخیر
- 🇮🇷 فارسی کامل + چیدمان راست‌به‌چپ (RTL)
- 💾 دیتا فقط روی دستگاه (SQLite) — در اولین اجرا داده نمونه لود می‌شود

## تکنولوژی

`Expo + React Native + TypeScript` + `expo-sqlite` + `zustand` + `nativewind` + `jalaali-js` + `react-navigation`

## ساختار

```
App.tsx                    — ناوبری (۵ تب + صفحه‌های استک)
src/
  components/              — BottomTabs, CalendarGrid, DateSelectModal, فرم‌ها, UI پایه
  screens/                 — Home, Tasks, Calendar, Habits, Ideas, Projects, ProjectDetail
  db/                      — schema.ts (جدول‌ها) + index.ts (CRUD)
  lib/jalali.ts            — تبدیل تاریخ شمسی/میلادی، ماه‌نما، فرمت‌ها
  lib/seed.ts              — داده نمونه اولین اجرا
  stores.ts                — استورهای zustand (ایده/پروژه/عادت/کار)
  types.ts                 — تایپ‌ها و برچسب‌های فارسی
```

## اجرای محلی

```bash
npm install
npx expo start          # Expo Go روی گوشی، یا --android / --ios
```

پیش‌نمایش وب (همین رپو خروجی build شده در `dist/` دارد):

```bash
npx expo export --platform web
node serve.mjs          # سرو dist روی http://localhost:8081
```

## بیلد APK

```bash
eas build -p android --profile preview
```

> قبل از بیلد، اکانت EAS لازم داری (`npx eas login` + `eas build:configure`).
> خروجی اندروید با `npx expo export --platform android` هم محلی verify شده است.

## نکات فنی

- تاریخ‌ها در دیتابیس به‌صورت ISO میلادی (`YYYY-MM-DD`) ذخیره می‌شوند و فقط برای نمایش به شمسی تبدیل می‌شوند.
- کتابخانه `jalaali-js@2` در تابع `toJalali` باگ دارد؛ در `src/lib/jalali.ts` با ترکیب `g2d` و `d2j` جایگزین شده و خروجی آن با تقویم رسمی (ICU) تست شده است.
- هفته از **شنبه** شروع می‌شود.
